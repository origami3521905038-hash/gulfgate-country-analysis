GulfGate تجمع الدولة والنطاق التنظيمي واستخدام المنتج ودور الشركة في الصفقة وحالة الأدلة ومرحلة التنفيذ في إطار تحليلي واحد، ثم تجيب عن أربعة أسئلة إدارية:

1. هل نتقدم؟
2. ما الخطوة الأولى؟
3. ما الشروط التي يجب تحققها قبل زيادة الاستثمار؟
4. ما الإشارة التي تستدعي التوقف أو تغيير المسار أو الانسحاب؟

## مدخل واحد ونتيجة قابلة للتنفيذ

- **تسلسل الدخول:** أي سوق وعميل ومسار تجاري نعطيه الأولوية؛
- **أدلة القرار:** ما يحتاجه الفريق للطلب والمشتري والشريك والوصول والتسليم والتحصيل؛
- **خطة العمل:** مهام 30 و60 و90 يومًا والمسؤوليات والمراحل وشروط التوسع؛
- **مذكرة للإدارة:** عرض موحد للفرصة والتكلفة والمتغيرات الحاسمة والخطوة التالية والموارد المطلوبة.

## مناسب لهذه الفرق

| الدور | النتيجة |
| --- | --- |
| المؤسس أو مسؤول المنطقة | مقارنة الأسواق وتسلسل الدخول وأولويات الموارد وبوابات المراحل |
| المبيعات والأعمال التجارية | تقييم المشتري والشريك وخريطة الشراء ومسار الصفقة والتحصيل |
| المشروع والتسليم | قائمة الوصول والاستيراد والتركيب والقبول والتشغيل المحلي |
| القانون والامتثال | مراجعة منظمة للدولة واستخدام المنتج وطبقات الأدلة وبنود التصعيد |

## ثلاثة حالات عملية متكررة

<div align="center">
  <img src="docs/images/cases-analysis.png" alt="Three Gulf market analysis use cases" width="100%">
</div>

1. **الإمارات · دخول تخزين الطاقة التجاري عبر موزع:** الانتقال من البحث عن موزع إلى تحديد المشترين ومسؤولية الاستيراد والخدمة الفنية وتجربة قصيرة لمدة 90 يومًا.
2. **السعودية · اختيار شريك للأجهزة الطبية:** فصل تسجيل الشركة ووصول المنتج والممثل المعتمد وأهلية المشروع وقدرة الخدمة.
3. **قطر · فحص مسبق لمناقصة مواد البناء:** مواءمة المشتري وأهلية الشراء والملفات الفنية والتسليم وشروط الدفع قبل التسعير.

يتحقق اختبار الإصدار من بيانات الترويسة والروابط المحلية ومسارات المعرفة وتحليل JSONL واختبار أداة البحث المحلية. يشغل GitHub Actions الاختبار نفسه عند كل دفعة وطلب دمج.

## سلسلة التحقق من المصادر الرسمية

عند التعامل مع السياسات والرسوم ومتطلبات الوصول وحالة المشروعات والمتطلبات القانونية، تعطي المهارة الأولوية للجهة المختصة وللنص الرسمي، ثم تسجل تاريخ النشر والنطاق ونسخة القاعدة وتاريخ التحقق.

تحتفظ التقارير المتقدمة بالمصدر الرئيسي بجوار الاستنتاج المرتبط به، لتسهيل مراجعة السلسلة كاملة من المصدر إلى الحكم والأثر والخطوة التنفيذية. وعند توفر أدوات الويب يمكن التحقق في الوقت الفعلي، بينما تدعم قاعدة المعرفة المحلية التحليل ومقارنة الحالات وقوائم الأدلة.
