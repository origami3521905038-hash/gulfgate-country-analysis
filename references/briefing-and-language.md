# 简报与语言规范

## 信息结构

默认使用 Markdown，兼容纯文本；不要依赖平台专有卡片、图标或写作块才能理解。标题直接写“对象＋任务＋简报”。

开头直接回答当前判断、主要理由、推荐路径和成立条件。优先写成一段连贯判断；几个结论确实彼此独立时再用少量要点，不固定数量。正文按任务组织关键事实、因果分析、方案取舍、经济/资源模型、路线图、风险与验证。关键引用贴近主张；复杂任务在末尾加简洁依据、假设与范围说明。无实际核验时不印“核验日期”。只在时效有意义时写报告日期，不从旧知识文件日期推算今天。

按任务复杂度选择深度：直接答复通常 300–700 中文字；决策简报通常 1200–2500 字；完整报告通常 2500–6000 字，材料充分或用户要求时可更长。单个术语可以更短；市场进入、营销、组织体系、投资、建厂或多年规划通常属于完整报告。依据不足不靠空话凑篇幅，而是明确假设、给出计算框架和验证路径。用户要求的长度、语言、格式优先。

栏目允许合并和自然改名，不要求机械列固定标题。不能省略会改变结论的未知项与条件。表格用于高密度比较、阶段路线图、成本模型和风险清单；长因果解释用段落。表格数量服从信息结构，不设一两张的上限，也不把所有内容塞进表格。

分析框架不等于成稿目录。事实、判断和动作能够在一个自然段中说清时，不拆成“事实—战略含义—建议”三个固定栏目。不同国家、方案和阶段的证据本来就可能不对称，不为版式整齐补齐同样数量的要点。

## 三种简报

- 研究：执行摘要 → 关键事实与机制 → 机会/约束及方案比较 → 模型与场景 → 推荐路径 → 路线图、KPI 与验证。
- 诊断：总体判断 → 成立的部分 → 假设及证据缺口 → 对目标/成本/进度的影响 → 修正方案与改变判断的条件。
- 预检：本次动作及准备状态 → 必须补齐/可并行事项 → 暂不宜承诺 → 现场问题或材料 → 完成条件、责任角色和后续节奏。

引用与范围按需要融入上述结构，不把研究日期、模式名、每一项内部标签都变成固定装饰。

## 自然语言规则

直接回应用户最关心的事。使用用户给出的产品、方案、对象和行动节点，但不把转述当核验。每个重要判断解释为什么以及对当前业务的影响。

语言平实、平等、克制。多用具体名词与动词，少用“赋能、抓手、闭环、全方位”等泛化表达。必要术语首次简释，避免连续缩写。可以用“你们”或企业名称，但不虚构亲历、人脉或情绪。正式报告保留必要的专业程度，不为显得自然而强行口语化。

不要固定寒暄、夸赞问题、重复用户原文、训诫、统一句长、满篇编号、固定收尾邀约或无关免责声明。少用装饰性粗体、口号式概括和连续的“不是……而是……”。不要把内部分析标签反复写成“核心结论”“战略含义”“真正的关键”。不要为了显得亲切而弱化证据边界。无依据不写“显然、肯定、必然”。

“加强尽调”改为说明向谁要什么、为何需要、何时满足。“存在不确定性”改为指出未知变量及其影响。“你们忽略了”改为“目前材料尚未说明”，除非已有证据证明实际遗漏。

## 表达对照（示范，不是事实）

机械：存在代理履约能力不确定性，建议加强尽职调查并审慎推进。

自然：现有材料还不足以确认代理能承担约定的办理工作。谈判前，建议先请对方说明办理范围、所需材料和双方责任，再决定是否对客户承诺时间。

机械：沙特市场前景广阔，建议抓住机遇，做好风险管理。

自然：目前材料能支持继续调查这条机会，还不足以支持扩大投入。下一步最需要确认的是具体买方的采购安排，以及你们能否满足交付要求。

上述句子只适用于示范设定；真实材料充分时应认可，不得复制“材料不足”作为固定开头。

完整简报或报告交付前，按[自然写作](natural-writing.md)做两遍检查：先核对事实、数字、限定、归因和来源，再处理重复、模板腔与排版。后一遍不得破坏前一遍保护的内容。
