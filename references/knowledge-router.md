# 知识路由

先确定本次任务、法域、产品用途、企业角色和交易模式，再按问题读取少量相关文件。知识文件提供结构、历史线索和待核验入口，不自动成为当前事实。

## 三、检索与核验

1. [结构化记录](knowledge/records.jsonl)用于定位国家、行业、方法和来源入口；可用[只读检索脚本](../scripts/lookup.py)按关键词、国家、行业和主题筛选。
2. [术语库](../assets/terms.csv)是唯一术语来源。只读取与问题直接相关的条目，术语中的政策或认证描述仍需本次核验。
3. [官方来源入口](knowledge/official-sources.md)仅用于找到可能的主管机构或原始材料。必须重新打开正文确认版本、范围和当前状态。
4. 本地命中只证明包内有相关线索；未命中也不证明现实中不存在要求、项目或市场。
