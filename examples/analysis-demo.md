# 国别研判示例：阿联酋市场进入 90 天预检

> 本文件是一份公开安全的匿名案例，展示从业务问题到决策简报到 90 天行动计划的完整输出。

## 案例库

| 场景 | 用户问题 | 输出重点 |
| --- | --- | --- |
| 阿联酋商用储能经销进入 | 是否通过当地经销商进入，如何验证 | 买方、伙伴、进口、售后、小单与回款 |
| 沙特医疗器械伙伴筛选 | 哪类伙伴可以承担注册、授权代表与售后 | 企业注册、产品准入、项目资格、服务能力 |
| 卡塔尔建材项目投标预检 | 是否适合在 30 天内提交项目方案 | 项目买方、采购资格、技术文件、交付与付款 |

## 用户输入

```text
使用 $gulfgate-country-analysis。
我们是一家中型商用储能企业，计划通过当地经销商进入阿联酋，暂无当地实体。
首批目标客户为工业园区和商业楼宇。请判断是否值得推进，并给出 90 天验证计划。
```

## 示例输出

**阶段结论：进入 90 天验证阶段，以真实项目、进口责任、售后能力和回款路径作为扩大投入的条件。**

### 先回答三个问题

| 决策点 | 当前判断 | 还需要什么 |
| --- | --- | --- |
| 市场需求是否足够具体 | 下一步聚焦 2–3 个可验证项目 | 具体客户、项目类型、采购触发和预算归属 |
| 经销商能否承担承诺 | 下一步按责任分项验证能力 | 牌照、进口责任、技术团队、案例、库存和售后能力 |
| 产品能否按目标用途落地 | 下一步建立产品—用途—准入对照表 | 型号、电网接入、安装地点、认证和项目审批要求 |

### 90 天行动

1. **第 1–15 天：锁定真实买方。** 选 2–3 个具体园区或楼宇项目，确认业主、采购人、设计方和 EPC 的角色。
2. **第 16–35 天：核查伙伴与进口链。** 明确 importer of record、仓储、安装、售后台账和停止合作条件。
3. **第 36–60 天：拆分准入层级。** 分别核对产品准入、项目准入、供应商注册和客户内部验收要求。
4. **第 61–90 天：跑一笔可复算的小单。** 验证报价、账期、保函/信用证、交付、售后和回款责任。

### 升级与停止条件

- **升级验证：** 出现明确项目、已验证的进口与售后责任人、可接受的回款路径。
- **暂停：** 经销商会面很热情，但始终无法提供牌照、技术团队和项目证据。
- **退出：** 产品用途触发无法满足的硬门槛，或现金流回收周期超过公司承受范围。

### 报告如何持续保持准确

正式报告会在对应结论旁附上主管机关、官方正文、发布日期、适用范围和本次核验日期。政策或项目状态更新时，可以沿着来源 → 判断 → 行动快速完成复核与改版。
